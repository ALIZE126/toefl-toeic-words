# 生词复习 · 托业 / 托福（本地版）

用自己的真题生词本复习：**短句理解 → 遮住答案主动回忆 → 隔天复习 → 换一句话再测**，第一版重点是**无字幕首听**。

技术栈：React + TypeScript + Vite。所有数据保存在浏览器本地（localStorage），不需要服务器和账号。

## 在 Mac 上启动

1. 安装 Node.js 20 或更高版本（已安装可跳过）：
   ```bash
   brew install node        # 或从 https://nodejs.org 下载安装包
   ```
2. 安装依赖并启动：
   ```bash
   cd ~/TypeScriptProject/words
   npm install
   npm run dev
   ```
3. 用 Safari 或 Chrome 打开终端里显示的地址：<http://localhost:5173/>

**手机上使用**：手机和 Mac 连同一个 Wi‑Fi，打开终端里 `Network:` 那一行的地址（如 `http://192.168.x.x:5173/`）。注意，手机上的进度单独保存在手机浏览器里，和 Mac 上的不通用。可以用「学习记录 → 导出备份 / 从备份恢复」在设备之间搬运进度。

想用打包好的版本：先运行 `npm run build`，再运行 `npm run preview`，然后打开 <http://localhost:4173/>。

## 导入生词本

1. 打开应用后点「去导入生词本」，或进入「词库 → 导入 Word 生词本 (.docx)」。
2. 选择「导入到：托福词库」（或托业词库），再选择附件：`~/Downloads/d6db85d0ed569a3bcec41d842a8f7965.docx`。项目里的 `fixtures/生词本.docx` 是同一份文件的副本，选它也可以。
3. 导入完成后会显示「读取 258 条，新增 258」，同时提示有 1 个疑似拼写错误（`permanet`）。在「词库 → 疑似拼写」里打开它，可以确认改为 `permanent`。更正后显示和发音都用新写法，词本原文保持不变。

导入规则：

- 读取 Word 表格里的「单词 / 音标 / 释义」三列（金山词霸「我的生词本」导出格式）。原始内容原样保存，在词条详情里以只读方式显示。
- 学习用的义项可以编辑：改中文义项、拆分或删除义项、补充搭配、题目来源和例句。例句可以标为「自编例句」或「原题例句（附出处）」。
- **增量导入**：词库里已经有词时，再导入会让你选两种方式之一：
  - **只新增词库里没有的词**（默认）：把金山词霸里的全量生词本重新导出、再导入，只会加入新词，追加在词库末尾。已有词条完全不动，包括原始音标和释义、编辑过的义项、例句和复习进度。导入结果会列出新增了哪些词，点「只看新增」或词库的「上次新增」筛选就能找到它们。
  - **新增，并更新已有词的原始音标 / 释义**：同样会加入新词，另外用文件里的内容更新已有词的原始音标和释义，并列出有变化的词。学习义项、例句和复习进度仍然保留。
- 匹配已有词条时不区分大小写。已确认的拼写更正也算已有：例如 `permanet` 已确认改为 `permanent` 后，新词本里的 `permanent` 不会被重复加进来。同一个文件里重复出现的词只导入一次。

## 第一次试用

1. 导入后进入「**今日复习**」，点「开始今日复习」。
2. 第一天都是**新学**卡片，默认每天 10 个义项，可在同一页的「设置」里调整。系统优先安排已经配好练习的 30 个词条：
   - **短句理解**：先读或听学习句，自己猜意思，再看释义。
   - 隔几张卡片后出现**文字回忆**：只显示单词，想好意思后点「显示答案」，再选「想起来了 / 有点模糊 / 没想起来」。
3. 第二天开始出现复习题，顺序是 **无字幕听力 → 新句理解 → 文字回忆**。听力题排在最前面，这样做听力时还没在文字题里见过答案。
4. 通勤时可以打开「设置 → **通勤模式**」：听力和新句理解不再显示选项，在心里作答后点按钮自评。

想提前体验第二天的复习，可以在地址后加上模拟日期，例如 `http://localhost:5173/?today=2026-11-17`。页面顶部会显示黄色的「模拟日期」提示。去掉参数就回到真实日期。

## 三种练习

| 练习 | 做法 | 记录 |
|---|---|---|
| 文字回忆 | 显示单词或短语。多义词会附上语境提示，如 `company property`。想好意思后显示答案并自评 | 想起来了 / 有点模糊 / 没想起来 |
| 无字幕听力 | 播放一句短英语（浏览器语音合成），可以重听，也可以慢速听。**提交前页面上没有句子、目标词、释义和翻译**，DOM 里也没有。提交后才显示字幕和解释 | 首听听懂 / 重听才懂 / 看字幕才懂 |
| 新句理解 | 换一句和学习句不同的例句，判断目标词在这句话里的意思。多义词的其他义项会作为干扰选项 | 答对 / 答错 |

无法播放语音时（浏览器不支持、系统里没有英文语音、播放出错或超时），听力卡会显示明确提示。可以选择「再试一次」或「改做文字题」：改做后显示英文句子，题目不变。文字替代题不计入听力成绩，这道听力题的排期也保持不变。

**AirPods 自动切换**：AirPods 同时连着 Mac 和 iPhone 时，只有 iPhone 开始「媒体播放」，耳机才会自动切过来。浏览器的语音合成不算媒体播放，所以应用在点播放时会先用 `<audio>` 播一段静音，等约 1.2 秒让耳机切过来，再开始朗读。一分钟内再次播放不再等待。这个功能在 iPhone / iPad 上默认开启，可以在「今日复习 → 设置 → 播放时把耳机切到这台设备」里关掉。如果耳机还是没切过来，可以在控制中心的音频输出里手动选 AirPods。

Mac 上如果听不到声音，请检查「系统设置 → 辅助功能 → 朗读内容」里是否有英文语音。也可以在「今日复习 → 设置 → 英文语音」里换一个声音。

## 界面结构（2026-11 改版）

视觉依据为 `design-reference/`（暖白背景、深青主色，本地文件，不上传）。手机端使用底部四入口，宽屏（≥720px）改为顶部同名导航。

| 入口 | 内容 | 原来的位置 |
|---|---|---|
| 今日 | 今日任务（待复习 / 新学义项 / 实际步骤）、开始或继续学习、专项快捷入口、学习设置 | 今日复习 |
| 专项 | 托业 Part 1（看图学短语、听音选图、练习题）、托福补词（3 篇短文） | 托福阅读、Part 1 专项 |
| 词库 | 搜索、筛选、词条编辑；「导入」面板含 Word 生词本和 Part 1 图片包 | 词库 |
| 记录 | 各能力成绩、容易混淆的动作组、详细统计、数据管理（备份 / 恢复） | 学习记录 |

右上角的「全部 / 托福 / 托业词库」下拉框控制今日、词库和记录。专项里的 Part 1 始终使用托业上下文。

- **练习页（专注页）**：顶部显示返回、类型和进度，中间是题目，底部是固定的操作区。操作区会让出安全区域，手机键盘弹出时会移到键盘上方。各题型的步骤：新学是「显示释义 → 继续」，文字回忆是「显示答案 → 自评」，客观题是「作答 → 反馈 → 下一题」。
- **继续学习**：作答阶段（是否已显示答案、选了哪项、听了几次、Part 1 的图片顺序）都保存在会话里。刷新页面或返回后，点「继续学习」会回到同一题的同一阶段。
- **只提交一次**：每张卡片的 ID 就是这次作答的标识，同一张卡重复提交只记一次。
- **托福补词**：有「上一空 / 下一空」，未提交的输入会自动保存。还有空没填时，第一次点「提交整篇」会提示剩几空，再点一次才真正提交。
- **图片**：按资产 ID（sha256）从 IndexedDB 读取。显示期间持有 object URL，不再显示后释放；页面从后台恢复时会重新读取。图片可以点开放大，关闭后焦点回到原位置。读取失败或缺图时，会显示原因和「重试 / 重新关联图片包」。听音选图需要的图片不在本机时不能作答，可以先跳过，这道题仍然保持待练。
- **存储版本**：`schema` 字段从 1 升级到 2，迁移前会保留一份副本（localStorage 键 `toefl-toeic-words/v1/snapshot`）。迁移可以重复执行，结果相同。恢复备份前也会先保存一份当前数据的副本。

## 托福阅读词汇册

「词库 → 导入 → 托福阅读词汇册」，选择 `阅读词汇数据.json`（2,333 条：2,291 个单词和 42 个搭配）。

- 导入到托福词库。可以只选部分分层：先背 239、进阶 720、话题识别 1,374。
- 每个词带一句托福阅读原文例句，并记录出处、出现篇数、词形和易混提示。例句来自本机题库，只保存在本机，不上传。
- 词典参考义会精简成学习用义项（每个词性取前 2 个意思），原始释义完整保留；人工整理释义原样使用。
- 已有的 155 个词（生词本和 Part 1 里的）不新建词条：同时加入托福词库，原题例句补进意思相同的义项。原来已有学习句的，原题例句会作为复测句，这样这些词就能做无字幕听力和新句理解。编辑内容和进度都保留。
- 新学顺序：内置练习词 → 先背 → 进阶 → 话题识别，同一层按出现篇数从多到少。每天新学数量最多可以设到 500，首页会显示还剩多少、按现在的速度几天学完、明天的复习量。
- 词库可以按「阅读词汇册 / 先背 / 进阶 / 话题识别」筛选，词条详情显示出现篇数和出处。

**存储**：词库和进度现在以 IndexedDB 为主存储，没有 localStorage 约 5 MB 的上限；能存下时 localStorage 也同步写一份。导入阅读词汇册后约 2.5 MB，之后每天几百条复习记录也存得下。

## AI 语音（ElevenLabs）

系统自带的语音太机械，而且 iOS 网页拿不到高级版语音，所以 Part 1 的句子改用 ElevenLabs 提前生成的 AI 语音。

- **生成**：执行 `node scripts/part1-audio.mjs [图片包.zip] [输出.zip]`。
  - API key 从 `~/.config/words-tts.env` 读取（`ELEVENLABS_API_KEY=` 或 `ELEVENLAB_API_KEY=`），不会进入项目或音频包。
  - 内容包括 Part 1 的场景句、原题句、听音选图播报句和 240 个短语，共 625 条、约 1.6 万字符，模型是 `eleven_multilingual_v2`。
  - 5 个声音轮换：Laura（美女）、Eric（美男）、Alice（英女）、George（英男）、Charlie（澳男）。同一句话总是同一个声音。
  - 生成过的会缓存在 `fixtures/tts-cache/`，中断后重跑只补缺少的，不重复扣额度。
- **导入**：「词库 → 导入 → AI 语音包」，选择 `words-audio-pack.zip`（约 12 MB，含 Part 1 句子和短语、生词本单词、内置例句共 977 条）。语音存在本机浏览器的 IndexedDB 里，按文字查找。音频包和图片包一样不上传，换设备或换网址需要再导入一次。
- **播放**：有 AI 语音的句子播放音频，「慢速」是 0.75 倍减速、音调不变；其余句子仍用系统语音。可以在「今日 → 学习设置 → 优先使用 AI 语音」里关掉。AI 音频走正常的媒体播放，AirPods 自动切换更可能生效。

## 托福词库 / 托业词库

- **导入时选择词库**：在「词库」页先选「导入到：托福词库 / 托业词库」，再选 .docx 文件。顶部选的是某个词库时，会默认导入到这个词库。
- **一个词可以同时在两个词库里**：导入时如果词已经在另一个词库里，不会再建一个副本，只会把它同时加入所选词库。原始释义、义项、例句不变，复习进度两个词库共享。导入结果会列出这些词。
- **切换词库**：顶部有「词库：全部 / 托福 / 托业」切换，按钮上显示各词库的词数。切换后，「今日复习」只出该词库的题，「词库」只列该词库的词，「学习记录」只统计该词库。「托福阅读 · 补全单词」不分词库。
- **新学额度**：「每天新学义项」是所有词库合计。比如设为 10，今天在托福词库学了 6 个，托业词库就只剩 4 个。
- **调整归属**：在词条详情顶部勾选「所在词库」。每个词至少要保留一个词库。
- **旧数据**：分词库之前导入的词（包括附件的 258 个）全部归入托福词库。

## 托业 Part 1 图片词库与专项练习

用来训练：听到动作或状态短语后，马上在照片里认出对应的画面。

**导入**（顶部切到「托业」→「词库」→「导入 Part 1 图片词库 (.zip)」）

- 选择 `toeic-part1-image-pack.zip`。ZIP 里要有 `toeic-part1-phrases-with-images.json` 和 `images/` 文件夹，JSON 放在 ZIP 根目录或任意一层文件夹里都可以。`image_path` 以 JSON 所在目录为基准。Mac 上右键文件夹选「压缩」就能得到这样的 ZIP。
- 确认前先显示预览：可导入的词条数、图片数（本机已有 / 待保存）、重复项（包内重复的 phrase_id、同名短语、和词库已有词条同名的词）、缺失图片，以及可判分的听音选图题和它们的校验结果。确认后才写入。
- 每条短语对应一个义项，按 `phrase_id` 绑定图片和出处。保留中文义项、原题出处（问题集、Test、题号、选项、正确选项 / 干扰项、PDF 文件名和页码）、视觉线索和注意事项。出处里的句子作为「原题例句」。
- 词库里已有同名词时：如果中文义项有相同的两字词（比如 `examine` 已有的「仔细检查」和 Part 1 的「检查、察看」），就复用这个义项，你的编辑内容和复习进度都保留，这个词同时加入托业词库。没有意思相同的义项时，就在这个词条下新增一个义项。
- 重复导入同一个包：已导入的短语只补齐缺少的数据（比如图片引用、新出处），不覆盖你改过的内容；本机已有的图片不会重复保存。
- 图片存放在浏览器的 IndexedDB 里，以图片内容的 SHA-256 为键，刷新页面后仍在。词条只保存图片引用。
- **图片加载不出来时**：「词库 → 托业」的导入面板和 Part 1 专项页会显示本机图片库的状态。图片只保存在导入时用的那个浏览器里：换网址（GitHub Pages / Netlify）、换浏览器，或者一个从 Safari 打开、一个从主屏幕图标打开，存储都不互通，需要在那边再导入一次 ZIP。iOS 把页面切到后台后，有时会断开 IndexedDB 连接，应用会自动重连；单张图读取失败时可以点「重试」。
- **备份**：JSON 备份不含图片。恢复备份后，重新导入同一个 ZIP，图片会按 `phrase_id` 重新绑定，复习进度不受影响。恢复时如果本机缺图，会提示有多少个词条需要重新绑定。

**练习**（「今日复习」在「全部」或「托业」视图下 →「托业 Part 1 专项」）

- **看图学短语**：浏览全部配图，可以按人物动作 / 物体状态 / 位置关系筛选或搜索。打开一张可以听短语、场景句和原题句，查看中文义项、画面线索、注意事项和出处。
- **听音选图**：播放一句英文，从两张图里选出匹配的一张。提交前页面上没有播报句、目标短语、答案和线索，图片的说明文字只写「图片 A / B」，每次随机排列。提交后显示原句和每张图的判断依据。语音播放不了时可以改为看句选图，结果不计成绩。
- 只有通过校验的题才进入正式复习：对照图至少 2 张且都有图片，每张都标为 `paired_photo_reviewed`（已和对照图一起审核），每道题的答案都在这组图里，播报句不重复。当前包里是 `reach for / hold` 的杯子对照图，共 2 题。其余 238 张图先用于学习。以后为同一短语配好新的对照图，会自动轮换场景复测，并且优先用和上次不同的一道。
- **练习题（自动出题）**：可以自己定本轮题数（5 / 10 / 20 / 全部，或自定义数量），也可以只出某一类（人物动作 / 物体状态 / 位置关系）。播报句用每张图的场景参考句，干扰图按这个顺序挑：
  1. 审核过的对照图（`reach for ↔ hold`）；
  2. 同一个「可做受控对照」组里的另一个短语（蹲 / 站、坐 / 站、在里面 / 在上面、扫地 / 拖地）；
  3. 类别不同的短语，比如人物动作配物体状态。

  「不适合作为直接对照」组里的短语可能同时成立，所以不会互相做干扰图。没练过的短语优先出。干扰图没有逐题审核，所以练习题只算练习：不进第 1、3、7 天复习，不计入首听正确率和常混淆统计。「学习记录」里单独显示「Part 1 练习题首听正确率」。

**排期和记录**

- 「Part 1 听音选图」是单独的一条进度，结果记为首听答对、重听后答对、答错。第一次做某道题相当于初学，次日开始按第 1、3、7 天复习；答错的本轮隔 3 题重做，并在次日复习。文字回忆、普通听力和托福拼写的进度互不影响。
- 到期的听音选图题会同时出现在专项和「今日复习」（全部 / 托业视图）里。托福视图不出 Part 1 题。
- 「学习记录」新增「Part 1 听音选图首听正确率」，只按正式复习的首次作答计算，本轮重做单独列出。还新增「常混淆的动作组」，统计你选错图时正确短语和选中短语的组合，并对应到图片包里的对照组名称，例如「伸手去取、伸进容器与已拿住」。
- 「词库」可以按 Part 1、人物动作、物体状态、位置关系筛选。词条详情会显示配图、线索和出处，没有对照题的图片也能在这里查看。

## 托福阅读 · 补全单词

模拟新版 TOEFL iBT Reading 的 **Complete the Words**，入口在顶部（手机上在底部）的「托福阅读」。

- **出题**：内置 3 篇原创学术短文（地球科学、生物学、气象学），每篇 75–80 词。首句完整保留，从第二句起每隔一个词去掉后半部分，共 10 空。词长为 n 时保留前 n/2（向下取整）个字母，例如 `car___` → `carved`。只数两个字母以上的单词，`a`、`I` 不计数，也不挖空。规则在 `src/lib/cloze.ts`，短文在 `src/data/passages.ts`。
- **目标词**：每篇有 3 个空来自生词本。第 1 篇是 carve、valleys、erosion，第 2 篇是 marine、colony、secrete，第 3 篇是 moist、precipitation、leeward。其余 7 个空是文中自然出现的普通词，而且不是生词本里的词。
- **作答**：段落原位显示前半个词，只输入缺少的字母。`Tab` 键切换到下一空，手机上按键盘的「下一项 / 回车」。输入框关闭了自动纠正、自动大写、拼写检查和自动填充。整篇提交后统一判分。
- **判分**：按文中实际词形判分，不区分大小写。`car___` 要填 `ved`，填 `ves`（carves）算错。
- **反馈**：逐空显示你的输入、正确字母和完整单词。生词本目标词还会显示义项，并用一句中文说明上下文里的词义或词形线索。提交前页面上没有答案、释义和线索。
- **进度**：10 空全部计入这篇短文的成绩。生词本目标词另外记一次拼写结果：
  - 拼错的加入「拼写复习」，次日出现在「今日复习」里，而且换一句话来考，比如 `The artist car___ a small bird out of wood.`。
  - 拼写复习也按第 1、3、7 天排期，和文字回忆、听力分开记录。所以同一义项可以是「文字已掌握 / 学习中、拼写待复习」。
  - 拼对的目标词不会加入拼写复习。普通词只计入短文成绩，不进入复习。
  - 「学习记录」里新增「生词本拼写正确率」和「补全单词短文得分率」两项。

## 复习排期

- 文字回忆、无字幕听力、新句理解三种练习**各自排期**。所以同一义项可以是「文字已掌握、听力待复习」，词库和词条详情里都会分别显示各自的状态。
- 初学后第 **1、3、7 天**复习。第 7 天那次也答对，就算「已掌握」。
- **答错、看字幕才懂、没想起来**：本轮隔 3 题后再出现一次，并从第 1 天重新排，也就是次日复习。本轮内的重做只用来练习，不会再改动排期。
- **重听才懂、有点模糊**：不升级，次日再练。
- 多义词按义项分别学习和排期，例如 `property` 的「特性；（物理、化学）性质」和「财产；房产」。

## 学习记录

「学习记录」页面显示：

- 无字幕首听正确率，以及首听听懂、重听才懂、看字幕才懂的次数
- 新句理解正确率、文字回忆正确率
- 每种练习的待复习、学习中、已掌握数量
- 最近 14 天的复习量
- 容易出错的义项、最近作答记录

正确率只统计正式复习。初学当天的回忆、本轮内的重做和文字替代题都不计入。

## 内置练习内容

`src/data/curated.ts` 收录了从词本中挑出的 30 个词条，共 41 个义项。每个义项有 1 个学习句和至少 1 个不同的复测句，复测句附带中文听力理解题。全部例句都标为「自编例句」。

- 场景搭配：postpone、seminar、policy、forecast、facilitate、investigate、merchant、hazard、accumulate
- 多义词（按义项拆分）：property、approach、commission、acquisition、retain、release、settlement、matter、discharge、concrete、colony
- 学术词：glacier、erosion、deposition、precipitation、habitat、organism、infer、emit、drought、artifact

例如 `postpone` 先用 *They postponed the seminar until Friday.* 学习，复习时播放 *We'll have to postpone the client meeting.*，并问「客户会议要怎么处理？」

其余 228 个词条按原始释义的词性自动拆出默认义项。在词库里给它们补上学习句，就能开始初学；再加一个不同的复测句，就能做听力题和新句理解。复测句可以设置中文听力理解题；不设置时，听力题会改问「关键词是什么意思」。

## 数据与备份

- 数据保存在当前浏览器的 localStorage 里（键名 `toefl-toeic-words/v1`），关闭或刷新页面后仍然保留。
- 换浏览器、换设备或清除网站数据之前，请先在「学习记录 → 导出备份」中保存 JSON 备份。
